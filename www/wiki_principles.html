Principles of msCNVS

Medium-throughput single-cell CNV sequencing with early barcoding and 2D fitting

1. Overview

msCNVS (medium-throughput single-cell CNV sequencing) is a sequencing method designed for clinical-grade single-cell copy number variation (CNV) profiling. It combines early-stage barcoding, Tn5-based tagmentation, and a two-dimensional fitting algorithm (2DFit) to produce accurate absolute CNV profiles without whole-genome pre-amplification (pre-WGA).

  • Early barcoding at the single-cell level
  • No whole-genome amplification (WGA-free)
  • Medium throughput (48–384 cells per run)
  • High uniformity and low bias
  • Accurate ploidy and CN calling via 2D fitting

2. Wet-Lab Principle: Early Barcoding with Modified Tn5

2.1 Tn5 Transposome Design

msCNVS uses a custom Tn5 transposome assembled from:

  • P5-Tn5 adapter containing an 8 bp cell barcode
  • P7-Tn5 adapter without barcode
  • Mosaic End (ME) sequence enabling Tn5 binding

Each single cell is processed in an individual well, where the P5 adapter uniquely labels the cell before pooling. After tagmentation, all wells are combined, and dual indexing (i5/i7) completes the library.

2.2 Workflow Summary

  • Cell lysis with protease
  • Tagmentation with barcoded Tn5
  • Pooling of all wells
  • PCR with i5/i7 indexes
  • NGS sequencing

3. Computational Principle: From Reads to CNV

3.1 Demultiplexing by Cell Barcode

Each read is assigned to a cell based on its embedded barcode:

$$\text{cell}(i) = c_k \quad \text{iff} \quad b_i = \text{barcode}(c_k)$$

3.2 Genome Binning and Read Counting

The genome is divided into fixed-size bins (e.g., 5k bins ≈ 0.66 Mb/bin). For cell \(c\) and bin \(j\):

$$R_{c,j} = \text{number of reads in bin } j$$

3.3 Depth Normalization

Let \(T_c = \sum_j R_{c,j}\) be the total reads of cell \(c\). Normalized read count (NRC):

$$\text{NRC}_{c,j} = \frac{R_{c,j}}{T_c} \times M$$

where \(M\) is a constant scaling factor (e.g., mean total reads across cells).

3.4 GC Correction

A LOESS curve is fitted to remove GC bias:

$$\hat{f}(g) = \mathbb{E}[\text{NRC}_{c,j} \mid g_j = g]$$ $$\text{NRC}^{GC}_{c,j} = \frac{\text{NRC}_{c,j}}{\hat{f}(g_j)}$$

3.5 Standardized Normalized Read Count (SNrc)

SNrc stabilizes variance and centers the signal:

$$\mu_c = \text{median}_j(\text{NRC}^{GC}_{c,j}), \quad \sigma_c = \text{MAD}_j(\text{NRC}^{GC}_{c,j})$$ $$\text{SNrc}_{c,j} = \frac{\text{NRC}^{GC}_{c,j} - \mu_c}{\sigma_c}$$

4. Two-Dimensional Fitting (2DFit)

4.1 Joint Estimation of Ploidy and Copy Number

2DFit simultaneously optimizes:

  • Global ploidy \(P_c\)
  • Integer copy number of each bin \(CN_{c,j}\)

4.2 Objective Function

Let \(\mu(k, P_c)\) be the expected SNrc for copy number \(k\) under ploidy \(P_c\). The loss function is:

$$L(P_c, \{CN_{c,j}\}) = \sum_j w_j \left(\text{SNrc}_{c,j} - \mu(CN_{c,j}, P_c)\right)^2 + \lambda \sum_j |CN_{c,j} - CN_{c,j-1}|$$

The second term enforces piecewise-constant CN segments (TV regularization).

4.3 Fuzzy Zone

Bins with ambiguous SNrc values fall into a “fuzzy zone,” where CN cannot be confidently assigned. msCNVS explicitly marks these regions to avoid false positives.

5. Summary

  • msCNVS labels each cell before pooling, enabling WGA-free single-cell CNV sequencing.
  • Normalization, GC correction, and SNrc produce a stable CNV signal.
  • 2DFit jointly estimates ploidy and CN, improving accuracy over 1D methods.
  • Validated against CMA, G-banding, and bulk sequencing with high concordance.
