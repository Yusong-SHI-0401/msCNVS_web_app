Analysis Pipeline

How msCNVS processes single-cell CNV data from raw reads to final CNV profiles

Overview

The msCNVS analysis pipeline transforms raw single-cell sequencing reads into high-confidence absolute copy number variation (CNV) profiles. The pipeline is implemented in R and follows a structured sequence of steps:

  1. Load genomic bins
  2. Mask problematic regions
  3. Compute normalized read counts
  4. Segment the genome
  5. Infer ploidy using 2D fitting
  6. Detect CN peaks
  7. Generate CNV and peak plots

Each step is configurable through the Web App interface, allowing users to fine‑tune analysis parameters for different sample types and sequencing depths.

1. LoadBins

The first step divides the genome into fixed-size bins and loads them into memory. These bins serve as the fundamental units for read counting and CNV inference.

  • Resolution: bin size (e.g., 600 kb)
  • Length: minimum bin length to retain
  • Genome: reference genome (hg19 / hg38 / mm10)

The read count for cell \( c \) in bin \( j \) is:

$$R_{c,j} = \text{number of aligned reads in bin } j$$

2. MaskBins

Certain genomic regions produce unreliable CNV signals due to repetitive sequences, assembly gaps, or structural complexity. msCNVS allows masking of these regions before segmentation.

  • centromere
  • clone gaps
  • contigs
  • heterochromatin
  • scaffolds
  • short arms

Masked bins are excluded from downstream segmentation and ploidy inference.

3. Segmentation

Segmentation identifies genomic regions with consistent copy number states. msCNVS uses a CBS-based approach with tunable sensitivity.

  • alpha: significance threshold for change‑point detection
  • nperm: number of permutations
  • undo.SD: undo threshold for merging segments
  • min.width: minimum number of bins per segment

The segmentation algorithm minimizes:

$$\sum_j \left( \text{SNrc}_{c,j} - \mu_s \right)^2$$

where \( \mu_s \) is the mean signal of segment \( s \).

4. InferPloidy (2D Fitting)

msCNVS uses a two‑dimensional fitting algorithm to jointly estimate:

  • global ploidy \( P \)
  • segment copy numbers \( CN_s \)

Search ranges:

  • m_start → m_end: slope range
  • b_start → b_end: intercept range
  • m_step, b_step: step sizes

The objective function:

$$L(P, CN) = \sum_s w_s \left( \bar{X}_s - \mu(CN_s, P) \right)^2$$

This identifies the ploidy that best aligns segment means with integer CN states.

5. Peak Detection

Peak detection identifies the SNrc peaks corresponding to integer copy numbers.

  • minpeakdistance: minimum distance between peaks

Peaks represent stable CN states such as 1‑copy, 2‑copy, 3‑copy, etc.

6. Plotting

The Web App generates two major visual outputs:

PlotPeaks

  • Width / Height
  • Units (in / cm / px)
  • DPI

PlotCNV

  • Genome‑wide CNV profile
  • Segmented CN states
  • Fuzzy zones

These plots provide a clear visualization of CNV structure across the genome.
